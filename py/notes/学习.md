
\## 第4阶段：文件操作



\### 4.1 基本操作



```python

\# 写入文件（自动创建）

with open("data.txt", "w", encoding="utf-8") as f:

&nbsp;   f.write("Hello, World!\\n")



\# 读取文件

with open("data.txt", "r", encoding="utf-8") as f:

&nbsp;   content = f.read()        # 读取全部 → 字符串

&nbsp;   # 或

&nbsp;   lines = f.readlines()      # 读取所有行 → 列表



\# 追加内容

with open("data.txt", "a", encoding="utf-8") as f:

&nbsp;   f.write("追加的内容\\n")

```



\### 4.2 文件模式



| 模式 | 说明 | 文件不存在时 |

|------|------|-------------|

| `"r"` | 只读 | 报错 |

| `"w"` | 覆盖写入 | 自动创建 |

| `"a"` | 追加 | 自动创建 |

| `"r+"` | 读写 | 报错 |



\### 4.3 `read()` vs `readline()` vs `readlines()`



```python

\# read() → 字符串

with open("data.txt", "r") as f:

&nbsp;   content = f.read()  # "第一行\\n第二行"



\# readline() → 字符串（一行）

with open("data.txt", "r") as f:

&nbsp;   line1 = f.readline()  # "第一行\\n"

&nbsp;   line2 = f.readline()  # "第二行\\n"



\# readlines() → 列表

with open("data.txt", "r") as f:

&nbsp;   lines = f.readlines()  # \["第一行\\n", "第二行\\n"]

```



\### 4.4 文件指针



```python

f = open("data.txt", "r")

f.readline()  # 读第1行，指针移到第2行

f.seek(0)     # 回到开头

f.readline()  # 重新读第1行

f.close()

```



\### 4.5 修改文件内容



```python

\# 读取 → 修改 → 写回

with open("data.txt", "r") as f:

&nbsp;   lines = f.readlines()



lines\[1] = "修改后的第二行\\n"  # 修改第2行



with open("data.txt", "w") as f:

&nbsp;   f.writelines(lines)

```

```python
\# 创建对象
```

\### 5.2 `self` 是什么？



`self` 代表\*\*当前对象本身\*\*：



```python

s1 = Student("张三", 85)

\# 调用 s1.show() 时，self = s1

\# 所以 self.name = s1.name = "张三"

```



\### 5.3 继承



```python

class Book:

&nbsp;   def \_\_init\_\_(self, title, author):

&nbsp;       self.title = title

&nbsp;       self.author = author

&nbsp;   

&nbsp;   def show(self):

&nbsp;       print(f"《{self.title}》- {self.author}")



class Ebook(Book):  # 继承 Book

&nbsp;   def \_\_init\_\_(self, title, author, file\_size):

&nbsp;       super().\_\_init\_\_(title, author)  # 调用父类初始化

&nbsp;       self.file\_size = file\_size

&nbsp;   

&nbsp;   def show(self):  # 重写父类方法

&nbsp;       super().show()

&nbsp;       print(f"  文件大小：{self.file\_size}MB")

```



\### 5.4 `super()` 是什么？



`super()` 代表\*\*父类\*\*，用来调用父类的方法。

\### 6.2 核心类设计



```python

class Book:

&nbsp;   """书籍类"""

&nbsp;   def \_\_init\_\_(self, book\_id, title, author, price, stock):

&nbsp;       self.book\_id = book\_id

&nbsp;       self.title = title

&nbsp;       self.author = author

&nbsp;       self.price = price

&nbsp;       self.stock = stock

&nbsp;   

&nbsp;   def borrow(self):

&nbsp;       if self.stock > 0:

&nbsp;           self.stock -= 1

&nbsp;           return True

&nbsp;       return False

&nbsp;   

&nbsp;   def return\_book(self):

&nbsp;       self.stock += 1



class Ebook(Book):

&nbsp;   """电子书类（继承 Book）"""

&nbsp;   def \_\_init\_\_(self, book\_id, title, author, price, file\_size):

&nbsp;       super().\_\_init\_\_(book\_id, title, author, price, 999)  # 库存无限

&nbsp;       self.file\_size = file\_size

&nbsp;   

&nbsp;   def borrow(self):

&nbsp;       return True  # 电子书永远可借



class User:

&nbsp;   """用户类"""

&nbsp;   def \_\_init\_\_(self, username, password, borrowed\_books=None):

&nbsp;       self.username = username

&nbsp;       self.password = password

&nbsp;       self.borrowed\_books = borrowed\_books or \[]



class BookStore:

&nbsp;   """书店管理类"""

&nbsp;   def \_\_init\_\_(self):

&nbsp;       self.books = {}

&nbsp;       self.users = {}

&nbsp;       self.current\_user = None

&nbsp;       self.load\_books()

&nbsp;       self.load\_users()

```



\### 6.3 文件读写



```python

def load\_books(self):

&nbsp;   """从文件读取书籍数据"""

&nbsp;   if not os.path.exists("data/books.txt"):

&nbsp;       # 创建默认数据

&nbsp;       with open("data/books.txt", "w") as f:

&nbsp;           f.write("B001|三体|刘慈欣|68.0|10|0\\n")

&nbsp;   

&nbsp;   with open("data/books.txt", "r") as f:

&nbsp;       for line in f:

&nbsp;           parts = line.strip().split("|")

&nbsp;           if parts\[5] == "0":

&nbsp;               book = Book(parts\[0], parts\[1], parts\[2], float(parts\[3]), int(parts\[4]))

&nbsp;           else:

&nbsp;               book = Ebook(parts\[0], parts\[1], parts\[2], float(parts\[3]), parts\[5])

&nbsp;           self.books\[parts\[0]] = book



def save\_books(self):

&nbsp;   """保存书籍数据到文件"""

&nbsp;   with open("data/books.txt", "w") as f:

&nbsp;       for book in self.books.values():

&nbsp;           f.write(book.to\_line() + "\\n")

```



\### 6.4 数据格式



\*\*books.txt 格式：\*\*

```

B001|三体|刘慈欣|68.0|10|0

B002|活着|余华|45.0|5|0

B003|Python入门|小明|38.0|0|2.5

```

\- 最后一位 `0` = 纸质书

\- 最后一位 `2.5` = 电子书的文件大小



\*\*users.txt 格式：\*\*

```

admin|123456|

张三|123|B001,B003
```

\## 第7阶段：GUI 图形界面入门



\### 7.1 第一个 GUI 程序



```python

import tkinter as tk



root = tk.Tk()

root.title("我的窗口")

root.geometry("300x200")



label = tk.Label(root, text="你好，世界！")

label.pack()



def click():

&nbsp;   label.config(text="按钮被点击了！")



button = tk.Button(root, text="点我", command=click)

button.pack()



root.mainloop()  # 保持窗口打开

```



\### 7.2 常用组件



| 组件 | 用途 | 代码 |

|------|------|------|

| `Label` | 显示文字 | `tk.Label(root, text="文字")` |

| `Button` | 可点击按钮 | `tk.Button(root, text="点我", command=func)` |

| `Entry` | 单行输入框 | `tk.Entry(root)` |

| `Text` | 多行文本框 | `tk.Text(root)` |

| `Listbox` | 列表 | `tk.Listbox(root)` |



\### 7.3 布局方式



```python

\# pack()：从上到下

label.pack()

button.pack()



\# grid()：表格布局（推荐）

label.grid(row=0, column=0)

entry.grid(row=0, column=1)

```
